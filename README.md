# Smitra Notice Board Manager

A notice board plugin for WordPress with pinned, urgent and expiring notices,
members-only restriction, a frontend submission form, a Gutenberg block and
an Elementor widget.

## Installation
1. Download the zip from the Releases page.
2. In WordPress go to Plugins → Add New → Upload Plugin.
3. Activate it and open Notice Board → Settings.

## Shortcodes
- `[noticeboard]`, `[noticeboard layout="grid"]`
- `[notice_submit_form]`
